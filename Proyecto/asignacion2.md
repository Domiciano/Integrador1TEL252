# Administración de datos
Desarrolle un módulo de administración de `Pacientes`, `Muestras` y `SensorData` que le permita *agregar*, *listar* y *eliminar* los datos de modo que pueda asignar muestras a un paicente.

`[20%]` Creación de pacientes
Backend + Frontend que permita agregar pacientes de acuerdo a la información consignada en el modelo que el grupo ha diseñado.

`[20%]` Listar paciente
Backend + Frontend que permita listar los pacientes

`[20%]` Listar las muestras
Debería poder listar las muestras tomadas para cada paciente

`[40%]` Creación de muestra
Debe ingeniárselas para crear la muestra, de modo que la muestra tomada por el ESP32 pueda ser asignada a un paciente específico. Por ejemplo quiero tomar una nueva muestra para el paciente `Andrés Andrade`, tomo la muestra con el dispositivo físico y luego la asignano al paciente y luego llega el paciente `Carlos Caicedo`, tomo la muestra se la asigno a este.
